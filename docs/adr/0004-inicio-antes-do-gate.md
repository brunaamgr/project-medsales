# ADR 0004: fundação local antes do Go/No-Go (D07)

> **Card:** F01 · 24/11/2026 · Aceito pela PO em chat

**Decisão.** Iniciar a estrutura base localmente antes do D07. A exceção não cobre deploy, staging nem dados reais.

**Motivo.** A stack é a mesma no plano B (VPS), então o risco de retrabalho é baixo.
